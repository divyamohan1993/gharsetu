# Getting help

GharSetu is a capstone project maintained by a student. Help is best-effort, not 24×7. Please pick the right channel below — it gets you a faster answer and keeps the issue tracker focused.

## Try it first

Live demo: <https://gharsetu.dmj.one>

The seed accounts work out of the box:

| Role    | Email                       | Password        |
| ------- | --------------------------- | --------------- |
| Student | `student@gharsetu.local`    | `Student@2026!` |
| Owner   | `owner@gharsetu.local`      | `Owner@2026!`   |
| Admin   | `admin@gharsetu.local`      | `Admin@2026!`   |

## I have a question

Open a thread in [GitHub Discussions](https://github.com/divyamohan1993/gharsetu/discussions). Search first — chances are someone asked the same thing.

## I found a bug

Open an Issue with the [bug report template](https://github.com/divyamohan1993/gharsetu/issues/new?template=bug_report.yml). Include browser, OS, page URL, reproduction steps, expected vs. actual.

## I have an idea or feature request

Open an Issue with the [feature request template](https://github.com/divyamohan1993/gharsetu/issues/new?template=feature_request.yml). Tell us who benefits and why.

## I want to add a translation

Open an Issue with the [i18n template](https://github.com/divyamohan1993/gharsetu/issues/new?template=i18n.yml), or jump straight in: copy `src/locales/en.json` to `src/locales/<code>.json`, translate, open a PR.

## I found an accessibility problem

Open an Issue with the [a11y template](https://github.com/divyamohan1993/gharsetu/issues/new?template=a11y.yml). Include the WCAG criterion, your assistive tech, and a page URL.

## I want to deploy this myself

Read [README.md → Deployment](README.md#deployment-to-cloud-run). The `deploy.sh` script handles the GCP plumbing.

## I want to contribute

Read [CONTRIBUTING.md](CONTRIBUTING.md). PRs welcome.

## Commercial or licensing inquiries

Email `contact@dmj.one`.

## Response expectations

| What | Target |
| ---- | ------ |
| Discussion replies          | within a few days |
| Bug triage                  | within a week     |
| PR first review             | within two weeks  |
| Critical / security reports | within 72 hours   |

This is a student-maintained project. We respond as time allows. Thank you for your patience.
